# ひだまり牧場

スマホのタップだけで遊べる、のんびり農場ぐらしゲームです。ブラウザで `index.html` を開くだけで動きます。

## あそびかた

- 地面をタップすると歩いていって、下のバーで選んだ道具を使います。
- 画面をスワイプすると景色を動かせます。右上の帽子ボタンでキャラクターの場所に戻れます。
- 畑を長押ししてからなぞると、まとめて作業できます。
- つりざおで池をタップすると釣り。浮きが沈んで「！」が出たらすぐタップします。
- 家をタップするとキッチンで料理ができます。料理は食べると体力が回復し、出荷すると高く売れます。
- 作物は春・夏・秋・冬あわせて15種類。冬もホウレンソウとハクサイが育ちます。
- クワで耕す → タネをまく → 毎日じょうろで水やり。水は池でくめます。
- 実った作物はタップで収穫。家の横の直売所で値段をつけて並べると、8:00〜18:00にお客さんが買いに来ます。
  - 市場価格は毎朝変わります。市場価格くらいなら売れやすく、高すぎると売れません。「自動」ボタンで市場価格に設定できます。
- 牧場には村人(ゲンさん・ミナ・ソラ)が遊びに来ます。話しかけると「おねがい」を頼まれ、達成するとごほうびがもらえます。毎日話したりプレゼントすると仲良くなれます。
- ニワトリをなでると、次の朝に大きなたまごを産みます。
- 牧場の右の牛舎には牛がいます。ミルカーを持って牛をタップすると乳しぼり(1日1回)。毎日なでるとミルクが大きくなります。
- 「手ぶら」を選ぶと、道具を使わずに移動だけできます(実った作物の収穫や、動物・建物へのタップはできます)。
- よろず屋 (8:00〜18:00) でタネ・ニワトリ・牛を買えます。
- 夜は家をタップして寝ましょう。深夜2時を過ぎると倒れてしまいます。

セーブデータは、遊んでいるブラウザの中に保存されます。
