# ひだまり牧場

スマホのタップだけで遊べる、のんびり農場ぐらしゲームです。ブラウザで `index.html` を開くだけで動きます。

## あそびかた

- 地面をタップすると歩いていって、下のバーで選んだ道具を使います。
- 畑を指でなぞると、まとめて作業できます。
- クワで耕す → タネをまく → 毎日じょうろで水やり。水は池でくめます。
- 実った作物はタップで収穫。家の横の出荷箱に入れると、翌朝お金になります。
- ニワトリをなでると、次の朝に大きなたまごを産みます。
- よろず屋 (8:00〜18:00) でタネやニワトリを買えます。
- 夜は家をタップして寝ましょう。深夜2時を過ぎると倒れてしまいます。

セーブデータは、遊んでいるブラウザの中に保存されます。
